# Roadmap

## Available

Core Chronicle authoring, Voyage hosting, player progression surfaces, profile
identity, Wayfarer history and artifacts, protected-content operations/media,
Harborlight Phase 3, True North navigation, Ledgerlight governance, Feature
Catalog governance, and Lanternwake presentation systems.

## In development

Broader validation of external operational integrations and refinement of
connected role experiences. The accepted P34-BME-20260729 exception leaves
browser-matrix remediation as validation work, not an implementation pass.

## Planned and research

Project Sounding Line, Harborlight Phase 4, Project Drydock, Project Landfall,
and Project Watchglass remain planned or governed work subject to accepted
design and validation. Dates are not committed here.

## Out of scope

This repository does not promise a generic game engine, unrestricted public hosting, or automatic publication of private Chronicle material.
