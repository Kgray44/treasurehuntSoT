# Upgrading

Read release notes, inspect migration requirements, back up the target, test the revision in an isolated environment, and confirm rollback readiness before production rollout. Run only the migrations associated with the selected version and verify a synthetic Player, Captain, and Creator flow afterward.

Do not infer migration compatibility from a branch name or a local database. See [deployment](deployment.md), [database and migrations](../developer/database-and-migrations.md), and [backup and recovery](backup-and-recovery.md).
