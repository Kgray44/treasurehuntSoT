# Self-hosting

Self-hosting requires a managed database, application runtime, secret management, backups, and an operational owner for private-content incidents. Run behind TLS, restrict database access, and use separately managed environments for development, staging, and production.

Before accepting users, verify authentication, migration state, backup recovery, and private-content controls with synthetic data. Follow [deployment](deployment.md), [backup and recovery](backup-and-recovery.md), and [private content](private-content.md).
