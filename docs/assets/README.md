# Documentation assets policy

Use only synthetic or generic data. Each screenshot or diagram needs a descriptive filename, meaningful alt text, source route, viewport, captured revision, capture date, owner document, and replacement or removal decision. Never capture private Chronicle content, credentials, or personal data. Store screenshots in `screenshots/` and diagrams in `diagrams/`; remove or replace an asset when its route or behavior is no longer current.
