# Account and workspaces

One Voyagewright account can open every workspace you have permission to use. You do not need separate sign-ins for Player, Captain, and Creator work. Access to another person's private material is never granted simply by opening a workspace.

You can be both a Captain and a Player in the same Voyage. Those roles remain separate: Captain controls help guide the Voyage, while the Player view shows only the experience available to the crew member. Opening both views does not switch a global account mode or transfer access between them.
