# Profile




Profile is the identity other people may see. In Personal Harbor, use **Public
Profile** to edit your display name, handle, biography, visibility, avatar, and
banner. The on-page preview uses the same server projection as the public
`/profile/[handle]` route, so hidden fields are not merely concealed by the
browser.







Profile is not Chronicle Passport. Passport is your private Voyage record;
Profile is a deliberately shareable projection. See [Chronicle
Passport](chronicle-passport.md) and [privacy](privacy.md).
