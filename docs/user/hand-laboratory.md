# Find the Hand

Open **Device connections → Find the Hand interaction laboratory** to explore camera visibility and calibration. Hand input is optional. Buttons, keyboard controls and the synthetic sliders remain available when a camera fails.

Choose **Enable live camera** only when you want local camera processing. The laboratory requests no microphone, uploads no frames and records no video. Use **Stop and delete calibration** to release the camera and clear the current fit. Mirroring changes the preview; changing it requires a new session.

Keep one relaxed pointing hand visible. Start nine-target calibration and point naturally at each displayed dot until it advances. Keep the camera and viewport stationary. The dots identify intended positions; clicking them does not validate hand pointing. After fitting, run independent validation. Those targets were not used to fit the model. Failed validation leaves the absolute estimate unavailable. Raw and filtered estimates are shown separately; snapping is disabled.

Synthetic replay is visibly labeled. Its sliders let you exercise the same calibration workflow without a camera. A successful synthetic result proves only the simulation workflow. Live physical accuracy, camera placements, left/right-hand usability and assistive use remain unqualified.

Resize, scroll, zoom, change cameras, move the camera or lose the hand during a trial and you may need to restart. Keep the calibration plane fully visible. This preview does not select objects, activate controls, manipulate artifacts or transfer content. Conventional Voyagewright controls continue to provide those outcomes.

The fit exists only in this session and expires after thirty minutes. Delete it to start again. Session diagnostics contain bounded reason codes and up to ten aggregate fit/validation summaries, including failed attempts. Delete calibration or stop to clear those summaries. Aggregate metrics can be downloaded only after you check the separate export consent box; they contain no video, landmarks or private calibration coefficients.
