# Community Harbor

Community Harbor is the controlled domain for shareable Chronicle packages and artifacts. Current mainline contains package, artifact, lineage, licensing, and authorization foundations. Availability of a hosted exchange depends on deployment configuration and should not be inferred from local development surfaces.

Use only material you have the right to share. Preserve attribution and do not publish private Chronicle content. For operational configuration see [private content](../administrator/private-content.md).
