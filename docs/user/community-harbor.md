# Community Harbor

Community Harbor is the controlled domain for shareable Chronicle packages and artifacts. Current mainline contains package, artifact, lineage, licensing, and authorization foundations. Availability of a hosted exchange depends on deployment configuration and should not be inferred from local development surfaces.

Use only material you have the right to share. Preserve attribution and do not publish private Chronicle content. For operational configuration see [private content](../administrator/private-content.md).

On the Project Homeport Phase 4 branch, Community Harbor is a visible global
destination from Home, public discovery, Player, Captain, Creator, and mobile
shell states. Harbor Home opens with featured, recent, updated, Creator, and
district shelves before search is required. Use the district navigator for
Chronicles, Artifacts, Templates, Maps, Audio and reveals, Creators,
Collections, Guides, and Voyage Logs. Search, sort, compact filters, advanced
filters, Back/Forward restoration, deliberate no-results, and safe detail
returns are supported.

Signed-in accounts can save eligible public content and follow eligible
Creators; anonymous controls return through the canonical sign-in. Missing
media uses a labelled fallback. Private, unlisted, quarantined, removed, and
archived material is not exposed as public discovery content. Installation or
remix actions remain explicitly unavailable when no accepted provider exists.
This branch is not on `main`, deployed, or owner accepted. Phase 5 exhaustive
route reachability and Phase 6 repository-wide completion remain separate.
