# Personal Harbor

Personal Harbor is the account control center: it groups account destinations with distinct noninteractive headings. Public Profile opens the public destination, Personal Information is the sole Display Name authority, Data & Account contains lifecycle controls, and Sign Out is a dedicated destination.

## Chronicle Passport

**Chronicle Passport** is a separate personal destination for what you experienced, rather than another account-settings directory. Personal Harbor gives it one concise summary and an **Open Chronicle Passport** action; Passport owns its own product navigation on desktop and mobile. Use it for private Voyage history, Timeline, People, Statistics, Voyage Atlas, Memories, artifact history, and other personal records. Use Personal Harbor for identity, preferences, privacy, security, sessions, support, and account management.
