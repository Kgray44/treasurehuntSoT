# Chronicle preview and start

Preview shows only the information a Chronicle can share before a Voyage begins. Starting a Chronicle is a deliberate choice to prepare a Voyage. Signed-in participants can use their display name and, where offered, a Chronicle-specific alias; guests can use the available guest-name flow.
