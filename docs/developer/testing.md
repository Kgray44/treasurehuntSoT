# Testing

Run focused unit or route tests while changing a domain. Before review, run formatting, lint, type checking, unit tests, build, private-content scanning, and documentation validation as the environment permits. `npm run validate` is the repository's complete gate.

Browser tests require isolated database and runtime configuration. A skipped external provider check is not a passing production proof. Record environment limitations in engineering evidence, not in current user guides.
