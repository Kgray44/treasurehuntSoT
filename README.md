# Chronicles

Chronicles is a collaborative, story-led platform for creating, running, and playing Voyages.

Players join invitations and follow a Chronicle through a library, journal, and replayable story surfaces. Captains prepare Voyages and guide live sessions. Creators use Creator Studio to assemble, version, and publish Chronicle material.

The current mainline includes account and role gateways, Player and Captain libraries, Creator Studio, immutable published versions, journals, invitations, Chronicle Passports, accessibility-aware presentation, and protected private-content workflows. Some integrations remain development-only or externally unvalidated; see the [current status](docs/product/current-status.md).
