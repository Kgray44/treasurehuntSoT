# Maintenance scope

Retain fixed, flushed start/end observations for build-tree fingerprint, final
dependency fingerprint and manifest write in the existing private preparation
output. Use tiny synthetic files and creation-owned forced stops. Preserve
hash/link/identity checks, resource and deadline gates, consumer sources and all
failed evidence. No product build, capture, full-tree benchmark, resume/rebind or
timeout extension is authorized by this diagnostic correction. It supplies no
qualification or acceptance authority.
