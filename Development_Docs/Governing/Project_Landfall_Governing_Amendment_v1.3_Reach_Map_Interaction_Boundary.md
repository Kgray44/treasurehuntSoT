# Project Landfall v1.3 — Reach Map Interaction Boundary

## Additive authority

This narrow amendment adds Reach to the accepted [Landfall v1.2 ownership boundary](Project_Landfall_Governing_Amendment_v1.2_Spatial_Ownership_and_Integration_Boundaries.md). Landfall's v1.0 and v1.1 Worldspaces requirements remain effective. It does not reopen the closed four-phase program or create a Phase 5.

## Map view input

Reach owns calibrated pointing, highlight, selection and requested pan/zoom/rotation intent. Landfall owns Worldspaces, routes, waypoints, location/context, journey state and navigation. A chart registers authorized view targets with semantic identity/version and conventional alternatives. Gestures change the presentation through the map adapter; they do not create alternate route, coordinate or position authority.

A hand pointing at a waypoint is not evidence that the Player physically arrived. A virtual chart rotation does not change Worldspace north. Selection of an authored marker cannot reveal hidden or unauthorized clues through snapping. Any request to edit an authoritative route uses the existing domain command/permission/version checks rather than treating Reach selection as authorization.

## Cross-project composition

Parallax owns world-anchored chart entities and spatial transforms. Crossdeck transfers chart presentation/custody while retaining a safe Landfall view reference. Storytide interprets accepted navigation outcomes; One Voyage owns progression. Reach never directly writes any of those states.

The browser baseline preserves conventional map controls if camera interaction is denied, unsupported, ambiguous or unqualified. Physical field navigation remains governed by Landfall's existing safety/privacy requirements; hand interaction cannot require the Player to stare at a screen while moving unsafely.

## Qualification and status

Future map integration must test viewport/zoom/mirror geometry, marker ambiguity, hidden targets, target/version change, gesture loss, input arbitration, and unchanged route/location/progression state during view-only manipulation. A synthetic adapter proves contracts, not a live Landfall/Reach integration or physical pointing accuracy.

This is documentation governance only. Accepted Landfall implementation and historical receipts remain intact. The [Reach governing document](Project_Reach_Spatial_Interaction_and_Intent_System_Governing_Document_v1.0.md) and [effective spatial authority](Voyagewright_Spatial_Experience_Effective_Authority.md) define the shared input and current integration chain.
