# Spatial Experience Refit readiness

This campaign installs experience enforcement. It does not implement the refit,
promote incomplete capabilities, or grant physical/owner acceptance.

The existing Crossdeck, Reach, Parallax and Sextant contracts retain their domain
ownership and gain protected `experienceIntent` requirements. An affected task
must supply complete semantic journeys, accepted references, responsive states,
honest capability tiers and one integration owner before qualification.

These are owner-reported baseline concerns awaiting rendered confirmation,
recorded in the existing Homeport nonconformity ledger. They are not measured
baseline waivers and do not make unrelated tasks fail. An affected completion
claim must demonstrate the actual promised experience. Future rendered evidence
must bind the precise source, actual states and meaningful negative cases.

The reusable A–H fixtures already protect these failure classes. The real account
recovery journey exercises the permanent capture/review/acceptance process.
The next refit can use this process directly; it must not create another policy,
role-label-only test, acceptance authority or animation system.
