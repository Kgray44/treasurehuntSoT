Reach does not wait for every unrelated Watchglass feature. Manual transfer does not wait for Reach. Landfall does not reopen.

## Runtime-compatible registry migration

A later Reach implementation must add the new owner to the strict Device Lab schema, resolve declarations into the shared catalog, preserve existing scenarios, update count-sensitive tests meaningfully and register executable adapters atomically. It must not simply mutate the accepted baseline JSON and break current loaders. The declarations remain pending until that work has actual evidence.

## Acceptance and phase discipline

All v1.0 consistency and Sounding Line requirements remain effective. This documentation PR uses focused registry/link/index and current Device Lab compatibility checks, then ordinary Sounding Line. Future product phases retain phase-safe merges and honest implementation labels. No declaration, simulated adapter or documentation merge qualifies natural pointing or completes a product phase.
