# Voyagewright Spatial Experience Architecture

This program home indexes the cross-project architecture for device context, multi-surface Voyages, spatial computing, augmented reality, adaptive spatial staging, physical-digital artifacts, and the shared Voyagewright Device Lab.

## Governing authority

- [Voyagewright Spatial Experience Architecture v1.0](../../Governing/Voyagewright_Spatial_Experience_Architecture_Governing_Document_v1.0.md) is the master cross-project governing baseline.
- Existing project authorities remain authoritative inside their owned domains. This umbrella document freezes boundaries and integration contracts; it does not silently absorb those projects.
- Project Sounding Line remains the repository-wide software verification authority. One Voyage remains authoritative for Chronicle progression.

## Canonical ownership introduced by v1.0

- **Project Sextant** — device context and hardware capability truth.
- **Project Landfall** — physical and virtual Worldspaces, place, routes, waypoints, journey state, and navigation.
- **Project Parallax** — spatial entities, Chronicle Lens spatial behavior, AR, anchors, adaptive staging, and shared spatial reality.
- **Project Crossdeck** — one-person/multi-surface session participation, pairing, synchronization, handoff, and reconnect.

Adjacent owners include Storytide, Watchglass, Figurehead, Wakebook, Drydock, One Voyage, Wayfarer, Harborlight, Sealed Hold, Helm, Lanternwake, and Sounding Line as defined by the master architecture.

## Device Lab rule

**Voyagewright Device Lab is shared platform verification infrastructure governed by Project Sounding Line. It is not a Project Landfall Phase 4 utility.** Projects register scenarios and assertions; Device Lab provides the common device/sensor/lifecycle/network/spatial execution facility and evidence; Sounding Line governs software verification and release authority.

## Current implementation status

The master architecture plus **Project Sextant v1.0** and **Project Parallax v1.0** governing baselines are now published. This does **not** claim that Sextant or Parallax are implemented; their implementation phases have not started. Project Crossdeck and the newly governed multi-surface capabilities likewise remain unimplemented.

Current protected main already contains the accepted Landfall v1.0/v1.1 architecture and Landfall Phases 1–3. Existing accepted Landfall browser/context seams remain compatibility truth until an explicit boundary migration changes them.
