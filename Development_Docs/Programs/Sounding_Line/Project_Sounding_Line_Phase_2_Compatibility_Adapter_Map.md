# Compatibility Adapter Map

The adapter catalogue is fixed in `scripts/sounding-line/adapters.mjs`.
Policy, inventory, runtime, docs, feature, architecture, language, privacy,
build and Prisma validation use argument arrays and `shell: false`. The
Harborlight browser-lane adapter has no caller-provided executable, spec, lane,
or port. `legacy-full` delegates to the unchanged global harness and is always
emergency-serial.

The compatibility query reports focused certification only for Sounding Line
and the three Harborlight Phase 4 focused surfaces. It reports global authority
for every release/full case.
