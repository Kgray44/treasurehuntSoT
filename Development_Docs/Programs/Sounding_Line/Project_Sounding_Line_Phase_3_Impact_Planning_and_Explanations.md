# Impact planning

The Phase 3 planner preserves Phase 1 selection semantics and augments each chosen suite with direct and expansion reasons. An unknown path, explicit uncertainty, critical risk, or a release request broadens the suite set; it never removes a suite. Every non-selected known suite receives an explicit machine-readable omission reason. Plan output is canonical and digestable from its stable inputs.

Release plans remain comprehensive. Capacity, duration history, and evidence reuse can influence scheduling and focused diagnosis only; they cannot silently weaken a release requirement.
