# Private current-run capture evidence

The existing capture source starts Playwright tracing before authentication and
publishes the canonical evidence folder, or failure staging, with plaintext JSON
and lifecycle receipts. Authentication fields are not excluded by that source;
session expiry or revocation before publication has not been proved. This is a
source exposure assessment. No actual live credential leak is established.

This local draft stops production publication until a separately approved
recipient and private reviewer/verifier access route exist. It removes the
plaintext capture/lifecycle/review/activation upload paths and checks the disabled
private policy before finite reservation. No workflow was dispatched, no real
private key was accessed, and no policy was installed by this work.

Generated-key fixtures exercise a distinct current-run packet purpose, encrypted
index, exact selected closure, source/provider binding and one-use publication
capabilities. Original media and producer JSON bytes are retained privately;
established remapped review JSON is also enclosed. Plan, prepublication journal
and current invocation lifecycle receipts remain private. Existing media hashes,
viewport dimensions, raw video/trace checks and paired witnesses are verified
before encryption and again on decrypted fixture bytes. Canonical history is
not promoted on this branch. Encryption and decryption do not establish product
acceptance or producer authorship.

Checkpoint03 used a provider-shaped callback without an authenticated archive
reader. The [preparation continuation](Project_Sounding_Line_Private_Capture_Preparation_Decision_Packet_20261023.md)
now implements explicit synthetic authenticated HTTP retrieval, bounded actual
archive digest/member/CRC/ZIP64 checks, and private reviewer/verifier adapters
with original source, run, context, media, paired and custody checks. These are
local generated-key fixtures, not live provider authentication or installed
access. Trusted upload-output wiring, real recipient/access selection and
protected production installation remain open. Native admission always rejects:
the full retained allocation exceeds the measured D: reserve budget, and native
write confinement has not been installed or proved.

Focused checks use generated keys, synthetic privacy canaries, original32generic
plus6paired fixture contexts and disposable private roots. They exercise wrong
source/run/attempt bindings, rejected keys, forged/cloned/concurrent tokens,
source mutation, ciphertext replacement, path escape/link rejection, exact size
caps, cancellation and fixed-size private reads. Linux/provider qualification,
independent frozen-source review, protected integration and landed-source checks
remain unclaimed. Failed local receipts are preserved outside the source tree.

The operational scope and remaining gates are recorded in
[the automation packet](../../../.agents/private-capture-evidence-repair.md).
This is partial infrastructure work, so no completed feature is added to the
Feature Catalog.
