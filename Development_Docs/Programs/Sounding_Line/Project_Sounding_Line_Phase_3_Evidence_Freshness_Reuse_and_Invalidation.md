# Evidence freshness and reuse

Freshness compares source watermark, policy, suite, fixture, environment, and cleanup identity. Missing identity is `UNKNOWN_CONSERVATIVE`; unclean cleanup is not reusable. Exact fresh evidence is eligible only for a focused decision after independent contract/risk review. It is never an authority shortcut for a release gate or the P34 exception.

The rerun planner invalidates changed roots and transitive dependent nodes. Unknown repair impact broadens all affected work. Retained nodes remain recorded as retained evidence rather than omitted silently.
