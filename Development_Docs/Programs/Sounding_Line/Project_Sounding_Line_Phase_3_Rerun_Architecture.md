# Surgical reruns

Rerun output identifies mandatory reruns and retained fresh evidence with a deterministic plan digest. Failed or repaired roots and their dependency descendants rerun. Fixture, test, policy, infrastructure, or unknown-impact changes broaden invalidation. The implementation exposes an explainable plan before any adapter executes it.
