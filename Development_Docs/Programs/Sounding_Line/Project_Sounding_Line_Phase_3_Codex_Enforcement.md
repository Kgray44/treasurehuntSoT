# Completion enforcement

The repository completion validator requires identity, selections, omissions, results, clean cleanup, and the Execution Usage Footer. It rejects stale reused evidence, unexplained omissions, mainline or release-authoritative wording, a green P34 claim, and an external validation claim without evidence. Enforcement remains repository-scoped and does not modify a global Codex installation.
