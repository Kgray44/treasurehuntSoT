# Project Sounding Line Program Completion Design Record

## Final family architecture

The active registry is schema 2.0.0 and is generated from executable source.
Every active case has one primary owned family, full safety/coverage metadata,
an expected duration, a hard budget, and an explicit current status. Ordinary
`unit.core`, broad `compatibility.browser`, and broad Vitest adapters are not
active suites. Family runners receive exact files from the sealed registry;
they reject empty selection.

Browser execution is focused by owned product contract. Mainline selects only
the isolated access sentinel; broader browser families are governed conditional
work and retain the recorded full-browser exception. P34 is never
selected or executed. Its semantic ledger maps every retained historical
identity to an existing focused test or a documented historical disposition.

## Stage 10 state

`STAGE_10_LEGACY_AUTHORITY_REMOVED` is the current integration status. Current
machine facts are generated by `scripts/sounding-line/test-registry.mjs` and
`scripts/sounding-line/reconcile-p34-ledger.mjs`; validation fails closed for
missing registrations, unknown suites, incomplete metadata, empty families,
or invalid P34 replacement IDs.
