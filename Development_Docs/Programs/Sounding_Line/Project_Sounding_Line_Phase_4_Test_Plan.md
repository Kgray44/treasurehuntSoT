# Project Sounding Line Phase 4 Test Plan

Focused contract coverage verifies enrollment identity, trust restriction,
capability matching, worker transitions and heartbeat identity, assignment
tamper/replay rejection, evidence digest/worker/cleanup binding, local/CI plan
parity, dual-run comparison, release vetoes, and sequential cutover with
rollback readiness. Phase 1-3 focused tests remain regression requirements.

The local test scope cannot prove hosted CI, remote-worker connectivity,
provider access, production signing keys, remote branch protection, or a green
P34 matrix. Those gates remain explicitly pending or non-green, never skipped
as a pass.
