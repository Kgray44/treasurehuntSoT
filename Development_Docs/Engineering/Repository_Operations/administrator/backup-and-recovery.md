# Backup and recovery

Back up the database and protected content stores on a schedule appropriate to the deployment. Protect backup credentials and test restoration into an isolated environment using synthetic verification accounts.

For an incident, preserve audit evidence, stop unsafe processing, identify the affected scope, and restore only through an approved process. A successful backup is not recovery proof; record a restoration rehearsal. Private-content operations are covered by [private content](private-content.md).
