# Repository operations records

This internal collection contains development, deployment, configuration, testing, and operational reference material. It is not part of the Voyagewright user guide and does not authorize public self-hosting.

- `administrator/` contains operations and provider configuration records.
- `developer/` contains development, architecture, testing, and documentation-governance records.
- `reference/` contains internal command, environment, route, and capability reference records.
- `product-status/` retains historical project and owner-review status records.
- `templates/` contains internal engineering templates.
