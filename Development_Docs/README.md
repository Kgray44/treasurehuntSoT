# Engineering records

This repository intentionally preserves Voyagewright's governing documents, decisions, project records, validation evidence, migrations, completion receipts, visual evidence, and selected development transcripts. These materials are first-class parts of the long-term development record, not disposable repository clutter.

Use [INDEX.md](INDEX.md) for the current taxonomy and [document-index.json](document-index.json) for the machine-readable inventory. Historical records retain their own claims; this index identifies their current location without rewriting them.
