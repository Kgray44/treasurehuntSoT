# Project Admiralty governing documents

This directory contains the governing product/architecture documents for Project Admiralty.

- [Project Admiralty v1.2 - Platform Administration and Operations](Project_Admiralty_Platform_Administration_and_Operations_Governing_Document_v1.2.pdf) is the parent Admiralty governing baseline.
- [Project Admiralty Governing Amendment v1.3 - The Support Pilot](Project_Admiralty_Governing_Amendment_v1.3_The_Support_Pilot.md) supplements v1.2 with autonomous support diagnosis, delegated execution grants, registered bounded repairs, postcondition verification, support receipts, and sanitized systemic-defect handoff.

The v1.3 amendment defines three supplemental mainline-safe increments after accepted Admiralty Phase 3:

1. **S1 - Open the Case**: support cases, user-consent binding, delegated read-only agent authority, typed diagnostics, and repair proposals.
2. **S2 - Turn the Wrench**: registered repair commands, R0-R4/RX risk classes, bounded execution, rollback/compensation, and postcondition verification.
3. **S3 - Close the Case**: complete autonomous support workflow, user/admin receipts, case history, pattern intelligence, and engineering handoff.

Until the amendment is accepted into protected `main`, the v1.2 document remains the effective mainline Admiralty governing authority. The amendment does not authorize Support Pilot implementation before its stated Admiralty Phase 3 prerequisite is satisfied.
