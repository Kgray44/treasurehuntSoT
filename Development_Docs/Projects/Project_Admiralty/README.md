# Project Admiralty

Project Admiralty establishes Voyagewright's governed platform-administration
authority. Phase 1, **Raise the Colors**, provides the least-privileged
capability resolver, explicit administrator bootstrap, session-bound privileged
assurance, user-approved Support Access, canonical audit evidence, the living
capability registry, and a deliberately limited secure `/admin` shell.

The Phase 1 shell is intentionally absent from ordinary product navigation.
That routing choice is not an authorization control: every projection and
mutation is independently authorized on the server.

## Authority

- Project Admiralty Platform Administration and Operations Governing Document v1.2
- Voyagewright Global Product Governance Standard
- Voyagewright Continuous Development and Mainline Integration Standard v1.0
- Project Sounding Line governing authority and accepted policy
