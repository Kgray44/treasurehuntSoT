# Project Admiralty Phase 3 command catalog

The machine-readable catalog is the command inventory. Wayfarer now owns the
partially implemented session-revocation and bounded account-suspension
extensions, and Harborlight owns the partially implemented canonical moderation
command port. The partial state is intentional: neither command family has
completed its required negative-path, accessibility, browser-journey, and
end-to-end qualification evidence. Role
assignment remains an owner-domain extension because the only current writer is
the one-time bootstrap reconciler; it must not be repurposed as an everyday
administrator role editor. No generic job or configuration mutation port was
found; those capabilities remain unavailable until a bounded owner contract is
implemented and proved. This document must not be read as an authorization to
operate a partially qualified command in a production environment.
