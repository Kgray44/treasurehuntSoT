## Storage, integrity and compatibility

No schema migration is introduced. PARALLAX_STUDIO is separated from the generic reusable-library UI. Working drafts use the existing mutable revision counter and reserved version number zero; a release inserts a new immutable positive version and atomically claims the revision. Historical releases never update when a draft changes. Every load and attachment verifies canonical checksums and owner/definition/version bindings. Chronicle-only items cannot attach to another Chronicle until explicit My Library promotion. Published capsules embed immutable content, so a runtime does not dereference a mutable library item.

The optional `studio` extension adds no default fields to P1 releases. Existing P1 checksums and capsules round trip unchanged. Native scene transport, capability discovery, companion compatibility and Device Lab ownership are retained. Behaviors emit visual/nonauthoritative interaction state, never Chronicle progression. UI accessibility and Guided meaning remain available without native AR.

## Explicit limits and remaining gates

Import manifests validate portable type, checksum, units, scale, complexity and provenance, but arbitrary model/texture/audio rendering is unavailable and blocks release. Complexity and synthetic fit estimates are not measured device frame rates. Crew preview is a second synthetic viewpoint, not Crossdeck synchronization. Remote comparison is fixed-scene comparison, not P3 adaptive resolution or calibration. Vision references preserve typed contracts without claiming Watchglass recognition.

No live provider is available in this task; schema/materialization/unavailable behavior is software-tested, while live model quality and provider operations remain an environment qualification gate. The provider must return the strict requested JSON shape. Tokens remain server-side and model output cannot mutate content without Creator review.
