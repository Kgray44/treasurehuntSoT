## Accepted continuity and unavailable live browser provider

`crossdeck.refit.published-lens` supply the formerly missing design. The existing
Gateway authorizes participation before personal Journal loading. Companion
Lens composes canonical Parallax binding/Inspect and accessible Guided return.
Presentation callbacks expose only the active modal's Voyage identity.

Crossdeck's `MAP`, `NOTE`, `ARTIFACT` references remain its wire scope. They do
not become a Scene graph, pose protocol or progression engine. Native mesh
selection is an intent; the canonical Player response authorizes the outcome.

`src/parallax/browser-world-tracking.ts` still declares no admitted live browser
engine. Production metric operation requires origin admission, fresh
`METRIC_6DOF` visual tracking and compatible owned presentation. Camera
permission, `POSITION_NO_SCALE`, a Lens role or fake plane flags cannot satisfy
it. Ordinary browser use stays Guided. Automatic classroom registration is
outside this bounded slice.
