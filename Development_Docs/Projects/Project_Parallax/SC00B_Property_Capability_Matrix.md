This matrix starts with the pre-refit Inspector on protected main `99a2babaefbbe051de0352c4aca22c8723b743b8` and reconciles the combined SC-00/SC-02 integration probe at `166e0ffeeb670b71745d3dc3353f2855420d5199`. These keep SC-00/SC-02's canonical data model and mutation helpers. The root-based candidate also contains the SC-01 Scene Manager host; final protected integration remains open. ## Depth and state rules

- `GUIDED`, persisted `DETAILED`, and `ENGINEERING` remain the three storage values. The middle choice is labeled **Standard**. Mode switching changes visible controls only; it never emits an edit.
- Standard and Engineering rotation/scale sliders show an ephemeral canvas preview while dragged. Pointer or keyboard release emits one canonical `TRANSFORM` history step; selection or mode changes discard the uncommitted preview.
- The three rail destinations are Properties, Spatial context, and Scene settings. Each preserves the selected entity. The active destination is announced by `aria-pressed`; the rail uses normal keyboard-operable buttons.
- An empty selection opens the scene overview. A missing selected entity or room feature shows an unavailable-selection state; Undo can restore a recently deleted item without losing its selection. An unapplied Assistant object shows a preview state and routes back to proposal review. Neither state mutates the scene. Locked objects remain inspectable, with unlock available outside the disabled edit fieldset.
- Choosing an ordinary asset from the Scene graph, Timeline, or a missing room-feature state exits room editing and clears stale room-feature selection. Its Properties then show the chosen asset and its accessibility controls; Undo remains available for a removed feature.
- Entering room editing from a selected asset clears that asset's selection and its object controls before the room editor opens.
- Typed SC-02 elements expose their common appearance or reach fields in Guided, useful falloff/timing fields in Standard, and implementation metadata, seeds or rolloff in Engineering. All depth variants call the same typed `CONTENT` patch through `SpatialElementInspector` and `spatialElementSchema`; mode changes never patch the element.
- Group Properties presents viewport tools in Guided and precise group transforms in Standard/Engineering. Spatial context presents member selection, group membership editing, grouping and ungrouping. The group Inspector does not expose the previously selected individual object's accessibility editor.
- Room and exclusion selections retain SC-00's `RoomEnvironmentEditor` and its authoritative room update port. The Environment state asks for an explicit feature selection instead of presenting the first feature as selected. Guided foregrounds relevant canvas tools and keeps room dimensions behind an explicit disclosure; Standard shows feature dimensions and yaw; Engineering also shows precise feature position and provenance. Structural support surfaces retain their fixed classification; the whole floor has no invalid rebuild or remove action. Other room and feature operations remain reachable through Standard/Engineering and the existing room tools. Mode travel does not mutate the room.
- A feature with no authoritative model or implemented editor is described as unsupported rather than rendered as a nonfunctional control. Qualify the SC-01 Manager host on the final integrated source before claiming complete type coverage.
- Before closeout, compare the implemented destinations with every row, run focused authoring tests, actual-browser interaction and screenshots for supported representative selections in every depth, then document the remaining schema-bound cases explicitly.
