# SC-00B property and capability preservation matrix

This matrix inventories the Inspector on protected main `4baa39af82b78b50a46f590bc2acc2ff0b7597aa`; the candidate later merged protected diagnostic base `99a2babaefbbe051de0352c4aca22c8723b743b8`, which did not change Parallax product source. The implementation owns the right Inspector and rail in `SpatialStudio.tsx`, with controls in `AdaptivePlacement.tsx`, `SpatialFieldQuality.tsx`, and `SpatialDependencies.tsx`. `changeHistory` in `src/parallax/authoring.ts` remains the mutation path for ordinary edits. The scene revision and autosave path remains in `SpatialStudio.tsx`.

**Current model boundary.** The authoritative entity schema accepts `PARCHMENT`, `MARKER`, and `TEXT`. A blank selection represents the scene overview. Furniture presets still resolve to those schema kinds; Environment and Scene are preview/definition concepts rather than selectable `SpatialEntity` kinds on this base. Groups are parent relationships rather than a separate entity kind. Exclusion zones, lights, effects, audio sources, and triggers are not selectable entities on this base. SC-01 is actively adding Scene Manager work; SC-02 is actively adding premium assets and effects. Their pending schemas must be integrated when available. This refit does not create competing entity schemas or present inert type-specific editors.

## Depth and state rules

- `GUIDED`, persisted `DETAILED`, and `ENGINEERING` remain the three storage values. The middle choice is labeled **Standard**. Mode switching changes visible controls only; it never emits an edit.
- The three rail destinations are Properties, Spatial context, and Scene settings. Each preserves the selected entity. The active destination is announced by `aria-pressed`; the rail uses normal keyboard-operable buttons.
- A missing or invalid entity selection resolves to the scene view without mutating the scene. Locked objects remain inspectable, with unlock available outside the disabled edit fieldset.
- A feature with no authoritative model or implemented editor is described as unsupported rather than rendered as a nonfunctional control. After SC-01 and SC-02 land, reconcile their new entity kinds against this matrix before claiming complete type coverage.
- Before closeout, compare the implemented destinations with every row, run focused authoring tests, actual-browser interaction and screenshots for supported representative selections in every depth, then document the remaining schema-bound cases explicitly.
