# SC-00B property and capability preservation matrix

This matrix starts with the pre-refit Inspector on protected main `99a2babaefbbe051de0352c4aca22c8723b743b8` and reconciles the combined SC-00/SC-02 integration probe at `166e0ffeeb670b71745d3dc3353f2855420d5199`. The right Inspector and rail live in `SpatialStudio.tsx`; typed controls remain in `SpatialElementInspector.tsx`, `SceneGroups.tsx`, and `RoomEnvironmentEditor.tsx`. Ordinary entity edits use `changeHistory` in `src/parallax/authoring.ts`; room, group, and Library edits retain their existing authoring ports. Revision and explicit-save behavior remain in `SpatialStudio.tsx`.

**Model boundary.** The protected baseline accepted `PARCHMENT`, `MARKER`, and `TEXT`; it did not have typed group, room-feature, or SC-02 element selection. The combined probe additionally presents selected editing groups and multiple items, authored room features and exclusion zones, and typed physical assets, lights, atmosphere, particles, projected effects, audio, phenomena, and interaction volumes. These keep SC-00/SC-02's canonical data model and mutation helpers. The SC-01 Scene Manager host remains in flight; this probe covers scene-level settings and an editable room but does not claim final SC-01 Manager integration or owner acceptance.

## Depth and state rules

- `GUIDED`, persisted `DETAILED`, and `ENGINEERING` remain the three storage values. The middle choice is labeled **Standard**. Mode switching changes visible controls only; it never emits an edit.
- Standard and Engineering rotation/scale sliders show an ephemeral canvas preview while dragged. Pointer or keyboard release emits one canonical `TRANSFORM` history step; selection or mode changes discard the uncommitted preview.
- The three rail destinations are Properties, Spatial context, and Scene settings. Each preserves the selected entity. The active destination is announced by `aria-pressed`; the rail uses normal keyboard-operable buttons.
- An empty selection opens the scene overview. A missing selected entity shows an unavailable-selection state; Undo can restore a recently deleted entity without losing its selection. An unapplied Assistant object shows a preview state and routes back to proposal review. Neither state mutates the scene. Locked objects remain inspectable, with unlock available outside the disabled edit fieldset.
- Typed SC-02 elements expose their common appearance or reach fields in Guided, useful falloff/timing fields in Standard, and implementation metadata, seeds or rolloff in Engineering. All depth variants call the same typed `CONTENT` patch through `SpatialElementInspector` and `spatialElementSchema`; mode changes never patch the element.
- Group Properties presents viewport tools in Guided and precise group transforms in Standard/Engineering. Spatial context presents member selection, group membership editing, grouping and ungrouping. The group Inspector does not expose the previously selected individual object's accessibility editor.
- Room and exclusion selections retain SC-00's `RoomEnvironmentEditor` and its authoritative room update port. The combined browser journey confirms their presence and three-depth screenshots. Its room fields remain dense, including in Guided; this is a visual review item rather than a claim of fully differentiated room depth.
- A feature with no authoritative model or implemented editor is described as unsupported rather than rendered as a nonfunctional control. Reconcile SC-01's final Manager host before claiming complete type coverage.
- Before closeout, compare the implemented destinations with every row, run focused authoring tests, actual-browser interaction and screenshots for supported representative selections in every depth, then document the remaining schema-bound cases explicitly.
