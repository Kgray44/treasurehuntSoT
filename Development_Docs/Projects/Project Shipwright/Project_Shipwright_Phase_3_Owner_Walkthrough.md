# Project Shipwright Phase 3: Owner Walkthrough

## Decision state

`READY_FOR_OWNER_WALKTHROUGH = NO`.

This is a walkthrough script and evidence checklist only. Owner acceptance has not been requested or recorded, and this document does not authorize a Sounding Line Mainline Decision.

## Demonstration flow

1. Sign in as a synthetic Creator through normal navigation and create/open a private Chronicle.
2. Open the Reuse tab and inspect the private Templates, Fragments, and Presets Library; confirm no unsupported block type or fake provider item appears.
3. Select a canonical Passage, create a bounded parameter slot for an existing canonical field, save a preset, then reopen it from the Library.
4. Supply the parameter, preview the use, confirm the normal save, and inspect that the result preserves source item/version provenance while ordinary autosave remains active.
5. Save a persisted multi-Passage selection as a fragment and inspect its explicit entry/exit connection guidance.
6. Select a compatible destination Passage, preview the planned insertion, review remapped identities/dependencies/lineage, then confirm only when Drydock has accepted the proposed graph.
7. Undo and redo the complete insertion and verify that source versions are snapshots rather than live mutable links.
8. Save a selected Chapter as a template, inspect required parameter/dependency messaging, and confirm cancel leaves the draft unchanged.
9. Open Installed Community content. When clean, eligible Harborlight metadata is present, inspect release/license/attribution/compatibility/update state and confirm it is read-only when no canonical reusable envelope exists.
10. Attempt an owner/Chronicle boundary misuse and confirm it fails closed without revealing another Creator's reusable content.

## Required review questions

- Are the Library categories and compatibility explanations understandable in Guided, Detailed, and Engineering disclosure modes?
- Does a parameter prompt present only safe authoring values and an existing field destination?
- Does the plan explain copied passages, Chapter changes, remaps, dependencies, ports, and provenance before mutation?
- Are unavailable Harborlight, Landfall, and Watchglass capabilities communicated truthfully rather than as active authoring?
- Can the whole flow be completed by keyboard and without drag-and-drop?

## Evidence still required before owner decision

- Current-main-reconciled candidate SHA.
- Fresh exact-source browser/accessibility/responsive evidence covering the complete insertion/undo/redo path.
- Isolated migration rehearsal and complete qualification matrix.
- Owner decision or explicit waiver under current governance.
