# Project Homeport Public Profile and Community Identity Contract

## Scope

One public identity. This contract repairs Round 2 realization while preserving specialist domain authority and prior accepted Homeport contracts.

## Required behavior

- Public Profile is the sole visible Community identity; Harborlight consumes only an allowlisted projection.
- An existing valid public handle automatically satisfies review identity.
- Missing setup links directly to Public Profile with a validated return target and restores the original composer.
- Private identity data and hidden handles never enter public projections or evidence.

## Verification

- existing Profile happy path
- setup and return
- tampered return target
- visibility/privacy matrix

## Truth boundary

Architecture freeze records the contract only. Implementation, evidence, Sounding Line release authority, and the owner's independent decision remain pending. No merge, deployment, live-provider proof, or owner acceptance is established.
