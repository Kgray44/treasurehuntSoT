# Personal Harbor correction contract

Normal subpages remove only the redundant `Current Area · Personal Harbor` panel. ProductShell context, active section,
breadcrumbs where applicable, restriction/unavailable/reauthentication/unsaved notices, and recovery states remain.

Group headings are noninteractive and visually distinct through spacing, muted typography, letter spacing, and optional
separators. Links retain readable size, indentation/rhythm, hover, active, focus, touch, mobile, narrow-mobile, and
effective-200-percent behavior. The final separated entry is faint-red `Sign Out`, leading to the canonical Phase 1
device/everywhere sign-out surface with identity, preservation explanation, pending/success/failure, cancellation, and
unsaved-work treatment.

`View My Profile` resolves the public handle and public projection, or focused handle setup with preserved return intent.
Personal Information alone edits Display Name; Public Profile edits handle, biography, visibility, imagery, and public
presentation while linking back to Personal Information for name changes. Data & Account groups Your data, Account
availability, and Danger zone with real export, deactivation, and deletion lifecycles.
