# Known limitations

- The walkthrough uses fictional synthetic content and a task-owned SQLite clone. It is not production data or
  production MySQL proof.
- External storage, malware scanning, identity providers, moderation providers, workers, and deployment behavior are
  not live-validated here. Unsupported actions remain visibly unavailable.
- Automated accessibility and keyboard/focus evidence does not replace a physical assistive-technology session.
- Full-page evidence capture may reposition sticky navigation during image stitching; this does not describe the live
  viewport behavior.
- The runtime is local to this Windows host. It proves the final publication build when the health receipt matches,
  not public availability.
- The owner decision remains pending regardless of automated pass state until the owner completes the walkthrough.
