# Journey observation checklist

Use these checks for each A-through-O journey:

- Start at Home and use only visible ordinary controls.
- Confirm the account name/state remains coherent across route transitions.
- Confirm each required primary action is visible, named, keyboard reachable, and not covered by sticky UI.
- Confirm pending, success, failure, expired, restricted, and unavailable states tell the truth independently.
- Confirm every contextual/detail route has a clear parent, return, or safe onward action.
- Confirm private Profile/Passport/Studio material does not appear on public Community surfaces.
- Confirm sign-out and recovery use authoritative server results rather than animation timing.
- On mobile, confirm the same functional destinations and no accidental horizontal document overflow.

For a defect, record journey letter, route, alias, viewport, exact visible control, expected state, observed state, and
whether reset reproduces it. Do not record credentials or real private content.
