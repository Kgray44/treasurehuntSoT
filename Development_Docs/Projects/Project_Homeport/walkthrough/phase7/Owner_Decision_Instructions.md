# Owner decision instructions

After completing the owner checklist and reviewing limitations, choose one outcome:

- `OWNER_ACCEPTED` — the observed product meets the owner walkthrough boundary.
- `OWNER_ACCEPTED_WITH_EXPLICIT_LIMITATIONS` — accepted with limitations written into the record.
- `OWNER_REJECTED_WITH_ACTIONABLE_FINDINGS` — not accepted; each finding includes a reproducible journey and expected
  correction.

Update `Project_Homeport_Phase_7_Owner_Decision_Record.md` only with the owner’s actual decision, date, runtime
publication SHA, checklist result, and notes. Do not infer acceptance from `RELEASE_GO`, a healthy runtime, screenshots,
or an engineering readiness statement.

Until that owner action occurs, the exact state is `PENDING_OWNER_DECISION` and `HP-NC-020` remains
`WAITING_FOR_OWNER_DECISION`.
