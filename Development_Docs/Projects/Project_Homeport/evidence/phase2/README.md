# Project Homeport Phase 2 curated evidence

This directory contains 20 synthetic after-state PNGs captured by the isolated `homeport-phase2` Chromium project. `Homeport_Visual_Baseline_Manifest.json` owns each evidence ID, implementation anchor, fixture checksum, browser/version, route, screen, journey, account state, workspace, shell mode, viewport, zoom, motion mode, screenshot checksum, observed result, and known limitation.

Every image was visually inspected after the final uninterrupted A-U run. The accepted set covers anonymous/authenticated desktop and mobile gateway states, anonymous/authenticated account hierarchy, public/global navigation, Player/Captain/Creator workspaces, Community visibility, mobile drawer, workspace switching, compact and immersive exits, unavailable context, 200% layout equivalent, reduced motion, and permission return.

All identities and Voyage content are reserved synthetic fixtures in a copied task-owned database. These images prove local rendered states only; they do not establish deployment, production data, live-user behavior, owner acceptance, Phase 3 Personal Harbor quality, Phase 4 Community reconstruction, or product acceptance. Phase 0 and Phase 1 evidence remain unchanged in their own directories.
