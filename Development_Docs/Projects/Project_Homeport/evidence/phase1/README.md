# Project Homeport Phase 1 curated evidence

This directory contains 15 synthetic after-state PNGs captured by the isolated `homeport-phase1` Chromium project. `Homeport_Visual_Baseline_Manifest.json` owns the evidence IDs, source boundary, fixture identity, routes, journeys, viewports, zoom levels, checksums, and review classification.

The screenshots contain reserved synthetic names only. They prove local rendered states, not deployment, production data, owner acceptance, or Phase 2/Phase 3 visual completion. Phase 0 before-state evidence remains unchanged under `evidence/phase0`.
