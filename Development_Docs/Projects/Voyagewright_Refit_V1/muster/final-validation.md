## Proven defects corrected during final validation

1. A selected cover's failed HTTP request incorrectly displayed the absent-cover artwork. The failure state now explains the temporary unavailability and offers retry; the approved successful image and absent-cover paths are unchanged.
2. Decorative icons were illegal siblings in definition-list groups. Hidden term wrappers preserve the exact grid/appearance while restoring valid semantics.
3. Twenty invited Crew overlapped chat/quote. The stage reserves lower-panel clearance only where actual Crew height requires it; a Crew-only resize observer handles live row growth. Disclosure, parchment and chat changes do not recalibrate anchors. The accepted 1280/1536/1920 desktop geometries and document heights still match the iteration-3 measurements.
4. Shared Light-theme rules made Crew names unreadable and replaced accepted room-control materials. Muster now retains its existing dark-stage text and controls inside the Light shell. Computed-color/material comparisons and actual screenshots verify the fix; no default-theme redesign occurred.

## Product-truth audit

Display aliases/profile names and validated profile-media URLs drive Crew identity; initial fallback avatars derive from names. `aggregateMembershipPresence` remains the sole source for known presence, with unknown explicitly represented. Captain authority and ordinary Player participation are independent. The preparing fixture now truthfully projects the owner's transferred Captain authority to Sera, while the accepted all-ready fixture retains the owner's departed Crew member and 3/3 count.

`VoyageCrewMessage` stores real Voyage/account-scoped messages. Every read/send checks current membership or authority; departed/outsider access is denied. Sender display names are captured at send time, while current authorized profile media supplies avatars. Shared event-bus arrival and reconciliation preserve existing history and unread behavior. Canonical launch, relinquishment, cancellation and Player leave were exercised on new disposable validation Voyages, never owner-review Voyages.
