# Phase 3 Privacy and Consent Matrix

Detailed records, reflections, Memories, and Keepsakes are `ONLY_ME`. Owner
queries require an account-rooted Wayfarer session and bind each record to that
account's PlayerProfile. Captain, Creator, public Profile, and Community routes
receive no Phase 3 detail projection. A participant can set only their own
consent after membership validation; another participant is omitted from every
Keepsake payload until their granted consent exists.
