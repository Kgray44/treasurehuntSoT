# Community Harbor Moderation Policy

Governed reason codes include spam, impersonation, harassment, abuse, privacy exposure, child safety, nonconsensual media, dangerous location, intellectual property, malicious package, malware, misleading listing, spoiler violation, license violation, prohibited content, and other. A reason code is a triage label, not a public verdict.

Cases are least-privilege by default. Moderators may not silently action their own content. Child-safety and nonconsensual-media reports receive immediate-safety priority. Public users never receive case detail, reporter identity, evidence, private notes, or another party's report text.
